# Letts Detail It: Website Redesign Concept

Redesign concept for [Letts Detail It](https://lettsdetailit.com/), an owner-operated drop-off auto detailing shop in Kalamazoo, MI. It keeps the content of the current site (services, condition-based pricing tiers, packages, FAQ, reviews, the owner's story) and moves it into one page with a calmer palette.

- Single static `index.html`, no build step
- Type: Archivo (Google Fonts, variable width axis). Headings use the expanded 125% width.
- Palette: warm off-white and charcoal, with one muted racing green (`#2F5B45`) as the brand color in place of the current all-green theme. Body text contrast is 6.3:1 or higher.
- Booking links go to the shop's existing Urable virtual shop. Phone links use `tel:`.
- On phones, a fixed bar at the bottom of the screen holds Call and Book.

## Content notes

- The current site says "4 cities served" but lists eight. That stat is replaced with "1 owner doing the work".
- The current site leaves the "Where are you located?" FAQ unanswered and lists no address, so this page sends people to the phone number for directions.
- No social links are on the current site, so none are here.
